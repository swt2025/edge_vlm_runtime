# EdgeVLM Documentation Pack

This folder contains the current project documentation extracted from the development discussion.

Files:

- `environment.md` — hardware/software/network environment
- `decisions.md` — important engineering decisions and trade-offs
- `experiments.md` — completed and planned experiments
- `problems.md` — troubleshooting knowledge worth keeping
- `notes/linux_shell.md` — compact reusable Shell knowledge

Recommended repository placement:

```text
edge_vlm_runtime/
├── docs/
│   ├── environment.md
│   ├── decisions.md
│   ├── experiments.md
│   └── problems.md
└── notes/
    └── linux_shell.md
```

Update these files during the project, but keep notes proportional to their value.
