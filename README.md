# EdgeVLM Runtime

Mixed-precision VLM quantization and C++ inference runtime for NVIDIA Jetson Orin NX 16GB.

## Target 

-Qwen3-VL-4B-Instruct as a primary candidate
-Qwen3-VL-2B-Instruct as fallback/development model
-TensorRT FP16 baseline 
-LLM INT4 AWQ
-Vision Encoder INT8
-C++ inference SDK
-Jetson performance/memory/power benchmarking
